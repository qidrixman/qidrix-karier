# Qidrix Карьер — диспетчерская АГМК (демо)

3D-диспетчеризация открытых горных работ на карьерах Кальмакыр, Ёшлик-1 и Сарычеку с беспроводной сетью Astrawireless ASTRADRIVE.

Это собранный сайт для GitHub Pages: здесь только готовые файлы, исходники хранятся отдельно. Не правьте файлы вручную — сайт пересобирается командой `npm run deploy:pages` в проекте «Qidrix Карьер».

Полезные ссылки (добавьте к адресу сайта):
- `?site=SITE-YSH` — открыть сразу нужный карьер;
- `?select=HT-101` — открыть сразу нужную машину;
- `?selftest` — встроенная самопроверка всех функций и производительности.
